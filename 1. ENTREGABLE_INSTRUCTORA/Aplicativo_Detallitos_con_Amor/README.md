# 🎁 Aplicativo Detallitos con Amor — Árbol de Talento Humano

## 📋 Descripción

Aplicativo web con escena 3D interactiva para Detallitos con Amor (regalos personalizados).
Misma estructura que el de Reflejos Brillantes pero adaptado a los colores y productos
de Detallitos con Amor.

## 🎨 Paleta de colores

| Uso | Color | Hex |
|---|---|---|
| Primario | Rosa magenta | #d7068e |
| Secundario | Rosa magenta claro | #d9308a |
| Texto | Café oscuro | #3f2620 |
| Fondo | Crema | #fffbf7 |
| Acento | Dorado | #ffd24b |

## 🌿 Productos artesanales dentro de la botella

Del catálogo de Detallitos con Amor:

1. Macetas con cactus y flores kawaii (limpiapipas)
2. Ramos temáticos personalizados (Bob Esponja, etc.)
3. Llaveros kawaii (9+ diseños)
4. Móviles colgantes decorativos
5. Macetas con tulipanes y margaritas
6. Detalles personalizados
