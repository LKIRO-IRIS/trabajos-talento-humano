# 🎯 Entregable Final — Instructora

Esta carpeta contiene el entregable final del proyecto para la instructora del SENA.

## 📁 Estructura

```
1. ENTREGABLE_INSTRUCTORA/
├── Capturas_Aplicativo_SIGTH/     ← Fotos del aplicativo que construimos
├── Manual_Uso/                     ← Manual de uso del aplicativo SIGTH
├── Presentacion_Instructora/       ← Presentación para mostrar a la instructora
└── Resumen_Proyecto/               ← Resumen ejecutivo del proyecto completo
```

## 📋 Contenido de cada carpeta

### Capturas_Aplicativo_SIGTH/
Capturas de pantalla del aplicativo web SIGTH que se construyó:
- Vista de la página principal (header con logo Reflejos Brillantes)
- Tab "Formatos Descargables"
- Tab "Gestión de Procesos" (archivador de procesos)
- TH-03 Hoja de Vida (con los 3 botones: Crear HV, Crear con IA, Subir HV)
- Formato Integral de Coordinación (con cajas C/NC)
- Lista de HVs analizadas con IA
- Banco de Talentos
- Sistema de respaldo (descarga .sigth)
- Modal de configuración de empresa

### Manual_Uso/
Manual de usuario que explica cómo usar el aplicativo SIGTH:
- Cómo configurar la empresa simulada
- Cómo crear una hoja de vida
- Cómo analizar hojas de vida con IA
- Cómo diligenciar los formatos TH
- Cómo descargar formatos en Word/PDF/Excel
- Cómo hacer respaldo del trabajo

### Presentacion_Instructora/
Material para presentar el proyecto a la instructora:
- Diapositivas o documento de presentación
- Demo del aplicativo
- Capturas destacadas
- Logros del proyecto

### Resumen_Proyecto/
Resumen ejecutivo del proyecto completo:
- Empresas simuladas trabajadas (Reflejos Brillantes, Detallitos con Amor)
- Cargos y candidatos gestionados
- Formatos generados (preselección y selección)
- Aplicativo web SIGTH
- Cantidad de archivos entregados
- Tecnologías utilizadas
