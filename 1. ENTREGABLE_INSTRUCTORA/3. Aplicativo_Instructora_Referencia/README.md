# Aplicativo de la Instructora — Biblioteca de Talento Humano

## 📋 Descripción

Aplicativo web desarrollado por la instructora del SENA como proyecto formativo.
Es una "Biblioteca de Talento Humano" con estantería virtual de libros interactivos,
donde cada libro representa un proceso de gestión humana.

## 🎨 Características

- Estantería virtual con 7 libros de colores interactivos
- Buscador de documentos
- Códigos estandarizados (TH-FR-XX para formatos, TH-MD-XX para modelos)
- Todos los documentos están "Pendientes" (sin enlazar)
- Desplegado en Netlify
- Datos ficticios con fines de formación SENA
