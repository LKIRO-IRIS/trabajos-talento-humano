## 🎯 Características del aplicativo

- **Concepto innovador:** Estantería virtual con libros interactivos por proceso
- **7 procesos de Talento Humano** organizados por colores
- **Códigos estandarizados** (TH-FR-XX para formatos, TH-MD-XX para modelos)
- **20 documentos** en total pendientes de enlazar
- **Desplegado en Netlify:** sweet-maneea-72183c.netlify.app
- **Datos ficticios** con fines de formación SENA
